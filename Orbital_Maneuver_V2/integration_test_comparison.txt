四、發現並修正的 Bug
════════════════════════════════════════════

問題根源
--------
原版 CSV 偵測邏輯（_collect_new_csv）使用集合差集：
  known_before = set(Path(".").glob(f"predictions_{norad}_*.csv"))
  # 執行 predict.py
  new_csv = [p for p in glob(...) if p not in known_before]

若先前已有同日期 CSV（如手動執行 predict.py 留下的 predictions_56105_20260523.csv），
predict.py 執行後只是覆寫同名檔，集合差集為空 → new_csv = None →
無法 rename → CSV created 檢查 FAIL → Step 7 也 FAIL（file missing）。

受影響衛星：56105（6 個 check 全部 FAIL）

修正方式
--------
改為「執行前先刪 today's CSV → 執行後直接 rename 指定檔名」：

  def _run_predict_and_rename(label, norad, pkl_path, target, *, extra_args=None):
      today_str = date.today().strftime("%Y%m%d")
      src_csv = Path(f"predictions_{norad}_{today_str}.csv")
      if src_csv.exists():
          src_csv.unlink()          # 刪除舊檔，確保 predict.py 建立的是全新檔案
      _run(label, cmd)
      if src_csv.exists():
          src_csv.rename(target)    # 直接 rename 到指定名稱
      return ok and target.exists()

此方式完全繞開集合差集偵測問題，適用於任何預先存在同名檔的情況。
