## 0. 手冊導讀

### 0.1 適用對象
系統操作人員、分析判讀人員、契約審查人員。

### 0.2 啟動方式
```bash
streamlit run maneuver_app_2026November.py
```

### 0.3 資料來源〔核實〕
- **本機模式**：讀本機 `space_db.duckdb`（頂層母庫）。
- **遠端模式**：設定環境變數 `HF_DATASET_REPO` 後，讀 HF Dataset `RhynoWu/satdashboard-db` 的 `space_db_slim.duckdb`（遠端 Parquet 模式）。
- 兩模式由 `scenario-advanced01`／`scenario04` 的部署架構決定，詳見記憶 `project_satdashboard_data_arch`。

### 0.4 資料更新節奏
- 每日 Space-Track 增量抓取 → 重建 slim DB → 發布，由 `update_slim_publish_hf.bat` 執行（第 0 步為 TLE 抓取，可用 `nofetch` 旗標跳過）。
- 〔已知問題〕GitHub Actions 自動化工作流「每日 TLE 更新與資料庫發布」自 2026-09-14 起執行失敗，原因未確認；目前以手動執行 `update_slim_publish_hf.bat` 維持更新。

## 2. 分析工具各區塊

### 2.0 🎯 統一偵測摘要（查詢後第一個區塊）〔核實｜更正大綱〕

> 大綱草稿誤記為「尚未對照程式確認」。已核對 `maneuver_app_2026November.py:13420–13455`：此功能**確實存在**，由 `orbit_anomaly_detector.OrbitAnomalyDetector` 提供，依軌域自動路由。

- 標題：「🎯 統一偵測摘要（orbit_anomaly_detector · 依軌域自動路由）」。
- 四個指標卡：**軌域 · 域**（軌道分類與 Starlink/非 Starlink 域）、**路由主判**（系統選用的主偵測器）、**融合旗標**（融合評分器旗標數與最大機率 `max_p`）、**Model 2 異常**（無監督偵測計數）。
- 若判定為自然再入衰減，以錯誤樣式（紅色）顯示「偵測到自然再入衰減模式 → 判定『{verdict}』」，不當作機動警報。
- 否則顯示「路由至 {主判偵測器} — {verdict}」，並附 Layer 2 統計事件數。
- 若 `orbit_anomaly_detector` 初始化失敗（如母庫不可得），顯示「統一偵測不可得：{錯誤訊息}」，不影響其餘區塊。

### 2.1 ① 軌道根數連續變化與差值〔核實〕
- 顯示半長軸（或高度，可切換）連續時序，疊加 NRLMSIS 阻力殘差標記的機動點（綠星）。
- 操作要點：右上角 radio 切換 Y 軸為「半長軸」或「高度」；圖表涵蓋所選日期範圍（見第 1 節查詢列的起訖日期）。

### 2.2 ② P1–P6 策略：個別 vs 合併〔核實〕
- 左表列出 P1–P6 各策略旗標數與類型（偵測／抑制），右側附每策略的設定說明文字。
- 合併列（combined）為最終旗標。
- 操作要點：展開「P2 / P5 拋物線曲線預覽」可視覺化側欄滑桿調整後的門檻曲線；側欄滑桿見第 2.9 節。

### 2.3 ③ 統計偵測層（CUSUM/BOCPD/SSA）＋ ML 偵測／預測〔核實〕
此區塊內容最多，依序呈現：
1. **軌域路由提示**：Starlink 域內→綠色成功訊息（主判為 Model 1）；域外→黃色警告（主判改為 NRLMSIS 阻力殘差）。
2. **主判結果卡**：三個指標，依路由顯示 Model 1 偵測數／NRLMSIS 交叉驗證數／Model 2 交叉驗證數（域內），或 NRLMSIS 主判／Model 2 支援／Model 1「—」（域外，因訓練分布外不採用）。
3. **四合一統計圖**：CUSUM、BOCPD、SSA、3σ-MAD 四條分數曲線疊圖，圈記各自判定的變化點，下方四個指標卡顯示各方法事件數。
4. **ML forecast（展開式）**：若 `Orbital_Maneuver_V2/models_meme_forecast` 模型可用，預測未來 1 天機動機率；模型或特徵不足時顯示提示文字而不報錯。
5. **ML 機動偵測（逐窗口）**：機率曲線＋操作門檻虛線＋偵測標記（X）；若全程 |Δa| 均低於自適應門檻，顯示「純阻力衰減/無機動」警告。
6. **Model 2（regime-agnostic）**：NRLMSIS 阻力殘差＋Isolation Forest 的無監督異常曲線。
7. **融合評分器**：CUSUM/BOCPD/SSA/MAD + NRLMSIS 合成的單一機率曲線＋操作門檻。
8. **SSA-RAG 自動解說**（側欄勾選「自動解說」時）：把本區塊偵測結果轉為自然語言敘述並呼叫 RAG 服務摘要。
- 操作要點：若 RAG 服務未上線，自動解說區塊會顯示連線失敗提示，不影響其餘圖表。

### 2.4 ④ 艦隊級統計（全 MEME 284 顆）＋ 95% 信賴區間〔已知問題：目前隱藏〕
- 程式碼第 13816–13817 行：`_SHOW_FLEET_STATS = False`，註解「使用者要求 2026-07-14：整段艦隊統計 + 95% CI 暫不顯示；改 True 即復原」。
- **此區塊目前不會顯示在介面上。** 本手冊保留說明以備日後重新啟用：功能為計算全 MEME 284 顆衛星的 30 天機動率 bootstrap 95% 信賴區間，並列出各偵測方法對照真值的 precision/recall/lead time。
- 大綱草稿編號為「④」，但介面實際渲染順序排在 ⑦ 之後、⑩ 之前（已停用狀態不影響順序判讀）。

### 2.5 ⑤ MEME vs TLE（僅 72h 模型，不做長時程外推）〔核實〕
- 僅當該衛星有本機 MEME 精密星曆檔（`data/raw/{衛星名}/`）時才顯示；否則顯示「無 MEME 星曆可比對」提示。
- 圖表：以 MEME 起始 72 小時內，TLE 傳播位置與 MEME 真值的距離誤差（公里），橫軸為 MEME 年齡（小時）。
- 操作要點：僅限 72 小時窗，不可解讀為長時程外推精度；中位與 95 百分位誤差顯示於圖說。

### 2.6 ⑥ 資料品質稽核（quality_flag：good／suspect／rejected）〔核實〕
- 五個指標卡：good 數與占比、suspect 數、rejected 數、重複 epoch 數、主要存疑原因。
- 散點圖依三種品質旗標著色，可 hover 查看原因。
- 非 good 的資料列表於下方表格。
- **判定規則**（程式內原文）：
  - **rejected** ＝ e∉[0,1) ／ sma≤R⊕ ／ inc∉[0,180] ／ checksum 錯。
  - **suspect** ＝ TLE 缺口 >48h（J2 外推誤差，見 NORAD 44349 案例）／ 單步 Δi>3° ／ \|B*\|>1。
  - 重複 epoch（≤60 秒）另計移除，不影響品質判定。
- 操作要點：全庫稽核可離線執行 `python data_quality_audit.py`。

### 2.7 ⑦ 星系級異常分析（軌道面 Δi std／批量機動／陣型誤差）〔核實〕
- 僅當查詢衛星屬於已知星系（`constellation_anomaly.CONSTELLATIONS`，如 Starlink／OneWeb／千帆／Yaogan／Gaofen／Jilin）才顯示分析按鈕；否則提示「非星系衛星」並列出已知星系清單。
- 操作要點：
  1. 滑桿選擇分析窗（7–60 天，預設 30 天）。
  2. 按「執行 {星系名} 分析」觸發計算（非自動執行，避免大型星系每次查詢都重算）。
  3. 三個指標卡：軌道面不一致數（① 軌道面一致性）、批量機動旗標數（② 批量機動識別）、陣型相位離群數（③ 陣型誤差）。
  4. 三個展開區塊可查看前 15 筆明細表。
- 執行時間：大型星系（如 Starlink 逾萬顆）約 10–20 秒。

### 2.8 ⑩ 合成 TLE 批次生成〔核實〕
- 參數：衛星數（1–500）、天數（3–120）、更新頻率（小時）、含機動比例、高度範圍、傾角範圍、ΔV 範圍、雜訊等級（LOW／MEDIUM／HIGH）、亂數種子。
- 按「生成」後產出含真實雜訊特徵的合成 TLE 文字檔，可下載（`synthetic.tle`）。
- 用途：對應招標規範「原始資料集蒐集和處理」中「自行產生具有真實特徵（含雜訊）的虛擬資料集」之要求。

### 2.9 ⑧ SSA-RAG 知識問答〔核實〕
- 展開式互動問答，需 SSA-RAG 服務上線（側欄可設定服務網址）；服務未上線時顯示提示文字，不影響其餘功能。

## 4. 常見問題與排除
| 現象 | 原因／排除方式 |
|---|---|
| 查無符合衛星 | 檢查 NORAD 編號或名稱拼寫；名稱查詢支援萬用字元 |
| 資料來源找不到 | 檢查本機 `space_db.duckdb` 是否存在，或 `HF_DATASET_REPO` 環境變數是否正確設定 |
| 遠端模式連線逾時 | HF Space 代理端偶發 502，屬平台端已知現象；前端已內建三層重試，稍候或重新整理即可（見記憶 `project_satdashboard_hf_serving`） |
| SSA-RAG 離線 | 自動解說與知識問答區塊會顯示連線失敗提示，不影響其餘圖表與指標 |
| ⑦ 星系分析按鈕消失 | 表示查詢衛星不屬於已知星系清單，非故障 |
| ④ 艦隊級統計看不到 | 目前設計如此（程式碼已停用，見 §2.4），非故障 |
