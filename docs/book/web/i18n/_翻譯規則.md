# 線上版英文、日文翻譯規則

## 來源與輸出
- 來源（唯讀）：`data/book/chapters/NN.md`（繁體中文，網頁匯出版；NN 為 01–21、A1、A2）。
- 輸出：英文 `docs/book/web/i18n/en/NN.md`，日文 `docs/book/web/i18n/ja/NN.md`。用 Write 工具寫入，UTF-8、LF 換行。
- 完成後執行驗證：`python docs/book/web/i18n/_verify_i18n.py en NN …`（或 ja），把報出的問題全部修到 OK。

## 不可改動（逐字保留）
- 圖片行 `![…](img/…)` 整行不動（含方括號內的編號文字也不改）。
- 所有 URL、數學式（`$…$`、`$$ … $$` 區塊內容）、上標數字 ¹²³…、`B\*` 的反斜線。
- Markdown 結構：標題層級與數量（`#`、`##`、`###`）、清單、表格欄數、引用區塊 `>`、空行分段。
- 所有數字、單位、日期、Case 編號、NORAD 編號、衛星名稱、人名的拉丁拼寫。數字的寫法保留（2,549 不改成 2549）。
- 不增刪事實、不補充解釋、不改變可能性用語的強度（「可能」不譯成確定）。原文的限定語（「在…假設下」「案例檔未載明」）都要譯出。

## 固定格式
- 章標題：英 `# Chapter 5　Atmospheric Drag, Space Weather, and False Maneuvers`；日 `# 第5章　大気抵抗、宇宙天気と偽のマヌーバ`；結語：英 `# Chapter 21　Epilogue`、日 `# 第21章　結語`；附錄：英 `# Appendix　Case Map`／`# Appendix　References and Further Reading`，日 `# 付録　事例マップ`／`# 付録　参考文献と関連文献`。
- 章標題下第一行加譯註（引用區塊，單獨一段）：
  - 英：`> *This English edition is an AI-assisted translation of the Traditional Chinese manuscript (v1.2, 2026-11-15). Where they differ, the Chinese original prevails.*`
  - 日：`> *この日本語版は、繁体字中国語原稿（v1.2、2026-11-15）をAIの支援により翻訳したものです。内容に相違がある場合は中国語の原文が優先します。*`
- 插敘標題列：原文 `**插敘：標題**` → 英 `**Sidebar: Title**`、日 `**コラム：タイトル**`（閱讀器依此前綴辨識插敘框，前綴必須完全一致）。
- 圖說：`照片 5-1　…` → 英 `Photo 5-1　…`、日 `写真 5-1　…`；`圖 5-1　…` → 英 `Figure 5-1　…`、日 `図 5-1　…`。第二行欄位：英 `Taken: …｜Location: …｜Photo ID: …｜Source: …`；日 `撮影日時：…｜撮影位置：…｜写真番号：…｜出典：…`。
- 證據方框欄名：證據等級／資料來源／真值依據／主要假設／限制／何時不應使用本方法 → 英 Evidence level／Data sources／Ground truth／Key assumptions／Limitations／When not to use this method；日 証拠レベル／データ出典／真値の根拠／主な仮定／限界／この手法を使うべきでない場合。等級：A｜已獨立重算 → A | Independently recomputed（日 A｜独自に再計算済み）；B｜官方或一手來源 → B | Official or primary source（日 B｜公式または一次資料）；C｜轉述且未驗證 → C | Reported, unverified（日 C｜伝聞・未検証）。
- 資料規格行：`**資料規格**：性質 …；資料期間 …；TLE 筆數 …；門檻 …；誤報率 …` → 英 `**Data specification**: Nature …; Period …; TLE count …; Threshold …; False-alarm rate …`；日 `**データ仕様**：性質 …；データ期間 …；TLE件数 …；閾値 …；誤報率 …`。
- 檢核清單 `- [ ] 能說明……` → 英 `- [ ] Can explain …`；日 `- [ ] …を説明できる。`
- 參考文獻：APA 條目本體（作者、日期、標題、刊名、URL）不改；只翻譯條目尾端括號內的中文註記（存取日期、本章用於、二手來源等）。中文標題的條目，英文版在原標題後加方括號英譯 `[English translation]`；日文版保留原標題。〈資料來源〉編號清單照譯，編號不變。
