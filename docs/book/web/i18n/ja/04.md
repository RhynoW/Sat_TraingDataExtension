# 第4章　衛星マヌーバの物理とミッションのロジック

> *この日本語版は、繁体字中国語原稿（v1.3、2026-11-19）をAIの支援により翻訳したものです。内容に相違がある場合は中国語の原文が優先します。*

## 章の導入

2019年9月2日、欧州宇宙機関（ESA）の風観測衛星Aeolusは、高度約320 kmの軌道上で、世界時10時14分、17分、18分の3回にわたって続けて噴射し、軌道を約350 m引き上げる予定であった。約半周後の11時02分、Aeolusは本来Starlink 44と会合するはずであった。このStarlinkは当時、推進系の試験のために、SpaceXが予定の550 kmから約310 kmまで意図的に降下させていたものである。

ESAが前日（日曜日）に最終決定を下した時点で、衝突確率は約1,000分の1であり、ESAの1万分の1という閾値の10倍であった。8月28日にESAはStarlinkチームに連絡し、相手側は1日以内に、現時点では対応をとる予定はないと回答していた。SpaceXが事後に述べたところによれば、当時算出された確率はわずか約5万分の1であり、確率が上昇した後、呼び出しシステムのプログラムの不具合によって当直要員はその後のメールを見ていなかった。これはESAが巨大コンステレーションの衛星を避けるために初めて行ったマヌーバであり、双方の調整は電子メールのやり取りに頼っていた。

地上から軌道データしか見られない者は、この3回の噴射が回避のためであり、別のことをしているのではないと、どうすればわかるのだろうか。

軌道上の衛星は静止しているわけではない。大気抵抗、重力摂動、ミッションの要求、衝突回避、寿命管理のために、絶えず軌道を調整している。衛星がなぜ動くのかを理解することが、軌道の異常を判断する第一歩である。本章ではCase 29のバングラデシュ衛星による手動の回避マヌーバを主要事例とし、マヌーバの目的、タイミング、意思決定の条件が、1回の軌道変化の安全保障上の意味をどのように決めるかを説明する。¹

## 学習目標

本章を読み終えた読者は、次のことを理解しているはずである。

- 軌道はなぜ自然に変化するのか。
- 衛星のマヌーバにはどのような種類があるのか。
- なぜ軌道長半径だけを見てマヌーバを判断できないのか。
- なぜマヌーバの国家安全保障上の意味は、目的と説明可能性によって決まるのか。
- なぜ衝突回避マヌーバには迅速で信頼できるリスク評価が必要なのか。

## 軌道は静的ではない

推進器が介入しなくても、衛星の軌道は時間とともに変化する。主な原因は次のとおりである。

- 地球の扁平性によるJ2摂動。
- 大気抵抗による軌道減衰。
- 太陽と月の引力。
- 太陽輻射圧。
- 地球の重力場の不均一。
- 宇宙天気による密度の変化。

写真 4-1　2024年の皆既日食におけるベイリー・ビーズとプロミネンス。米国テキサス州ダラスで、皆既日食が終わった直後の瞬間に、月の縁から漏れる「ベイリー・ビーズ」と太陽のプロミネンス。皆既日食は太陽、月、地球がほぼ一直線に並んだときに起こる。太陽と月の引力は地球周回軌道上の衛星も常に引っ張っており、上に挙げた軌道の自然な変化の原因の一つである。

## 衛星マヌーバの種類

衛星のマヌーバは多くの種類に分けられる。

| 種類 | 目的 | 典型的な特徴 |
|---|---|---|
| 軌道保持 | 抵抗と摂動を打ち消す | 小幅、周期的 |
| 軌道上昇 | 運用高度への投入または減衰の補償 | 軌道長半径の増加 |
| 軌道降下 | 軌道離脱、再突入、ミッションの調整 | 軌道長半径の減少 |
| 衝突回避 | 会合リスクを下げる | 短時間、特定の方向 |
| 位相調整 | コンステレーション内の相対位置を調整する | 軌道に沿った方向の変化 |
| 傾斜角調整 | カバーする緯度を変える | まれで燃料を多く消費する |
| 寿命末期の処置 | 衝突と破片のリスクを下げる | 軌道降下または軌道離脱 |

**コラム：2021年、宇宙ステーションが風雲1号Cの破片を回避**

2021年11月10日世界時20時15分、国際宇宙ステーションにドッキングしていたProgress MS-18補給船が361秒間噴射し、宇宙ステーションの軌道を1,240 m引き上げて420.72 kmにした。ロシア国営宇宙公社によれば、調整しなければ風雲1号Cの破片の一つが翌朝約600 mまで接近するところであった。この破片は第1章で触れた2007年の衛星破壊実験によるものである。上の表と照らし合わせると、これは典型的な衝突回避である。短時間の噴射で方向が明確であり、目的は会合リスクを下げることだけにある。

## なぜ軌道長半径だけを見てはならないのか

軌道長半径はマヌーバを検出するための重要な信号だが、唯一の証拠ではない。

軌道長半径が低下した場合、考えられるのは次のとおりである。

- 大気抵抗。
- 能動的な軌道降下。
- 軌道離脱作業。
- 寿命末期の減衰。

軌道長半径が上昇した場合、考えられるのは次のとおりである。

- 軌道上昇。
- 一括での上昇。
- 軌道保持。
- 展開後の運用軌道への投入。

したがって、システムは複数の軌道要素、物理モデル、コンステレーションの挙動を組み合わせてはじめて、信頼できる判断を下すことができる。

![照片 4-3](img/nasa/s125e007066.jpg)

写真 4-3　アトランティスの貨物室に固定されたハッブル宇宙望遠鏡。STS-125ミッションで、ハッブルは地球周回軌道上で捕獲された後、スペースシャトル・アトランティスの貨物室内に固定された。シャトルがハッブルに追いついて捕まえるには、まず一連の軌道マヌーバでランデブーを完了しなければならない。この種の能動的な接近も、本書が検出しようとするマヌーバの種類の一つである。

## マヌーバの時間スケール

衛星のマヌーバは次のように分けられる。

- ステップ型マヌーバ：短時間で完了し、軌道長半径に明らかな跳びが現れる。
- 漸進型マヌーバ：低推力で長時間かけて完了し、変化が複数のTLEに分散する。
- 継続的な保持：周期的な小幅の調整。
- 異常な挙動：ミッション、物理、コンステレーションのベースラインのいずれでも説明できない。

漸進型の低推力マヌーバは、低軌道の電気推進衛星の検出における主な課題である。同じ正味の軌道長半径の変化量でも、漸進アークの形で行われると1ステップの増分が分散され、隣接する2件の変化だけを見るL1ルールではフラグを立てにくくなる。最終報告書は、数日にわたる漸進的な変化の検出率は1回の階段状変化よりはるかに低いと指摘している。R7は、複数日にわたる同方向の変化を「連続マヌーバ区間」としてまとめ、各ステップは閾値未満でも合計が閾値を超える変化を低信頼度レビュー項目として補うが、これらの項目は候補イベントには数えず、分析者が判読しなければならない。³

## 主要事例：Case 29　バングラデシュ衛星の手動回避マヌーバ

> **証拠レベル：C｜伝聞・未検証**
>
> **データ出典**：2026年のバングラデシュのメディア（The Daily Star、TBS News）と台湾のメディア（民生電子報）が伝えたバングラデシュ衛星会社（BSCL）幹部の説明。ほかにWikipedia「INSAT-1A」とGunter's Space Pageの項目を参照。本プロジェクトのデータベースにはBS-1（NORAD 43463）とINSAT-1A（NORAD 13129）のTLEは収録されていない。
>
> **真値の根拠**：なし。確認時点で、「破片はINSAT-1Aに由来する」あるいは「最接近距離852 m」について、インド政府または独立した第三者による裏づけは見つからなかった。
>
> **主な仮定**：メディアが伝えた事象の経緯（Space-Trackの警報、手計算、小幅な移動の後の元の位置への復帰）は、運用者の実際の作業をおおむね反映している。
>
> **限界**：**本プロジェクトは独自に検証しておらず、再計算もしておらず、この事象についていかなるマヌーバ検出も行っていない。これは外部事例の引用であって、本プロジェクトの検証成果ではない。**一部の報道の公開日時の表示が確認時点の日付と合わず、古い記事の転載である可能性も排除できない。事象が2026年8月に起きたという点は完全には確認できない。INSAT-1Aが制御を失って退役した時期は報道によって記載が異なる。
>

### 事例の背景

Case 29は実際の手動回避マヌーバを描いている。バングラデシュの衛星が、VCMも商用の衝突回避ツールもないなかで、公開警報と手計算に頼ってインドの退役衛星の破片を回避したというものである。²

この事例は本プロジェクトの実測分析の事例ではなく、Case 28に対応する現実世界の対照として位置づけられる。その価値は本プロジェクトのシステムがこの事象を検出したことを示す点にあるのではなく、次のことを示す点にある。衝突警報、軌道の不確実性、意思決定の時間的圧力が同時に存在するとき、衝突回避マヌーバは理解され、検証され、迅速に行動に移されなければならない宇宙安全の行為である。

事象の詳細は、バングラデシュのメディア（The Daily Star、TBS News）と台湾のメディア（民生電子報）が伝えた衛星運用者の説明によるもので、確認時点でインド政府または独立した第三者による裏づけは見つからなかった。本プロジェクトもこの事象についていかなる再計算や検証も行っていない。

これらの報道によれば、破片が通過した際のBS-1との最接近距離は852 mで、衛星は損傷しなかった。この距離も運用者の説明にすぎず、独立した裏づけはない。

### 衝突回避マヌーバの意思決定の連鎖

有効な衝突回避マヌーバには、通常次の手順が含まれる。

1. 会合警報を入手する。
2. 最接近時刻と距離を評価する。
3. 衝突確率と不確実性を推定する。
4. マヌーバが必要かどうかを判断する。
5. 回避の方向とΔVを計画する。
6. マヌーバを実行する。
7. 新しい軌道とその後の会合リスクを検証する。

Case 29は、高度な商用ツールがなくても、公開警報、手計算、迅速な意思決定によって衝突を回避できる可能性があることを示している。しかし同時に一つのリスクも露呈している。軌道の不確実性に関する十分な情報がなければ、人の判断は早すぎる、遅すぎる、あるいは方向を誤るリスクに直面しうる。

**コラム：2020年、宇宙ステーションの緊急軌道上昇**

2020年9月22日、ある破片が国際宇宙ステーションの近くを通過すると予測され、最接近は約1.39 kmであった。警報が届くのが遅かったため、3名の乗組員はロシア区画に移ってソユーズの近くで退避に備えるよう指示された。米東部時間午後5時19分、Progress 75が150秒間噴射して軌道を引き上げ、NASAは乗組員が危険にさらされたことは一度もなかったと述べた。NASAは事後、破片がGOSAT-2を打ち上げたH-2Aロケットのフェアリングのカバーに由来することを突き止めた。それは7月に高度約600 kmで破砕し、その一片が抵抗によって宇宙ステーションの高度まで引き下げられ、5日後に再突入した。警報から噴射まで、意思決定の連鎖全体が1日足らずに圧縮されていた。

### 国家安全保障上の含意

衝突回避マヌーバの国家安全保障上の意味は、マヌーバそのものではなく、次の条件にある。

- 信頼できる警報を適時に入手できるか。
- リスクを正しく評価できるか。
- 迅速に計画し実行できるか。
- 二次的な会合や新たなリスクを避けられるか。
- 情報が不十分なときに責任ある判断を下せるか。

これらはまさに宇宙交通管理と衝突リスク管理が取り組むべき問題である。

**コラム：Sentinel-1Aの140 m**

2022年5月16日、ESAのSentinel-1Aは軌道を140 m変更し、数cm大のCosmos 1408の破片を回避した。回避しなければ、ほぼ正面衝突になる可能性があった。ミッション管制が受けた警報は24時間足らず前で、計画にかけた時間はわずか数時間であった。Cosmos 1408の元の軌道はSentinel-1Aより約200 km低かったが、2021年に衛星破壊ミサイルで破壊された際の爆発のエネルギーが、一部の破片をSentinel-1Aの軌道まで押し上げたのである。マヌーバの量は小さく、鍵は警報が信頼できるかどうか、意思決定が十分に速いかどうかにある。

## マヌーバと国家安全保障

衛星マヌーバの国家安全保障上の意味は、その目的、タイミング、対象、説明可能性によって決まる。

- 通常の保持：予測可能で、帰属でき、リスクは低い。
- 衝突回避：誤判断を避けるため、迅速に確認しなければならない。
- 一括展開：コンステレーションの戦略を理解する必要がある。
- 異常な軌道降下：故障、制御喪失、軌道離脱を意味する可能性がある。
- 異常な接近：ランデブー、サービス、偵察、非協力的な行動にかかわる可能性がある。
- 保持の停止：寿命末期である可能性もあれば、ミッション失敗の初期の兆候である可能性もある。

本研究ではFORMOSAT（福衛）7号のFS7-3を例とする。同機の最後のマヌーバは2025年5月で、その後14か月間軌道保持がなく、高度は549 kmから536.5 kmに下がり、他の5機との差は41 kmとなった。システムが公開TLEから見て取れる事実は「軌道保持の停止」である。原因が推進系の異常、推進剤の枯渇、退役計画のいずれであるかは、運用者のテレメトリで照合しなければならない。³

- [ ] 軌道長半径がなぜ主な信号であるが、唯一の証拠ではないのかを説明できる。

- [ ] マヌーバの国家安全保障上の意味がなぜ説明可能性とリスクによって決まるのかを説明できる。
- [ ] 軌道データにおける「平常からの逸脱」、確認済みのマヌーバ、マヌーバの意図を区別できる。軌道長半径の1回の変化は、抵抗、軌道保持、衝突回避のいずれにも由来しうる。平常からの逸脱を検出してもマヌーバが確認されたことを意味せず、マヌーバと確認されたとしても、敵意や違反を意味するわけではない。
