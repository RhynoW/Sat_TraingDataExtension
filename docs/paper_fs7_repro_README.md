# Reproducibility README — Empirical Sensitivity Model for TLE-Based Maneuver Detection (FS7)

Companion to `paper_fs7_sensitivity_model_EN.md`. This README specifies the
environment, data retrieval, the exact command reproducing each table and
figure, expected output checksums, and the fixed random seeds.

## 1. Environment

- OS: Windows 11 (analyses are OS-independent; paths use POSIX-style throughout)
- Python ≥ 3.13 with: numpy, pandas, scipy, duckdb, sgp4 (≥ 2.25), matplotlib
- Exact versions used for the published numbers: see `fs7_env_freeze.txt`
  (generated by `pip freeze`, shipped with the release)

## 2. Data retrieval

| data | source | how |
|---|---|---|
| leoOrb SP3 daily packs | TACC, `https://tacc.cwa.gov.tw/data-service/fs7rt_tdpc/daily_tar` | `python -m formosat7_leoorb.cli download --start YYYY-MM-DD --end YYYY-MM-DD` (public, no login). Campaign windows used: 2024-07-08→08-01, 2024-11-18→12-13, 2025-05-01→05-25, 2025-06-20→09-10, 2026-01-13→02-03, plus the 2024 storm sample. File versions/download dates/checksums: `fs7_checksums_sha256.txt` |
| TLE histories | Space-Track (user's own credentials; raw TLEs are **not** redistributed per the user agreement) | NORAD IDs 44343/44349/44350/44351/44353/44358; epoch lists shipped as metadata; retrieval via the project's `download_TLE_unified.py` into `space_db.duckdb` (table `raw_tle_archive`) |

percentile CIs, seed 42. c CI: profile likelihood, ΔlogL ≤ 1.92.

## 4. Expected output checksums

SHA-256 of every analysis script and derived table/JSON:
`data/benchmark/fs7_checksums_sha256.txt` (regenerate with
`python fs7_make_checksums.py`). Figures are excluded from checksumming
(matplotlib output is backend-dependent); their underlying CSV/JSON are covered.

## 5. Seeds and configuration

All randomness flows through `numpy.random.default_rng(42)` set at the top of
each script; no wall-clock or environment-dependent values enter any result.
Analysis constants (window length 40, stride 20, clean-step 0.3 km, gap 5 d,
tolerance ±2 samples / ±1.0 d, Δa grid, decimation {1,2,4}) are defined at the
top of `fs7_injection_sweep.py` and imported by every later stage.
