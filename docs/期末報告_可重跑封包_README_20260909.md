|---|---|---|

**審查意見回應之獨立複核**（本輪新增之統計量，皆可由現有輸出檔重新驗算，非新跑分析）：
- Wilson 95% CI（large 召回、small 召回、FPR）：由對應之 n/k 直接以 Wilson 公式計算，公式與計算過程見技術附錄相應章節之【審查意見回應】框。
- unseen-satellite hold-out 之 large 事件數（n=81）：讀取 `data/benchmark/three_layer_perunit_20260803.csv`，以固定隨機種子（`np.random.default_rng(2026)`）重現同一保留衛星集合即可複算，過程見技術附錄十三之審查回應框。
- 式 (4) RAAN 漂移率獨立驗算：`Ω̇_J2 = -1.5·n·J2·(R_E/p)²·cos(i)`，參數與計算過程見技術附錄二之審查回應框。

## 四、已知限制（誠實揭露，供複核者知悉）

1. **版本控制現況**：本報告撰寫時，工作目錄約有 **360 個檔案尚未 commit**（`git status` 可查），Git HEAD 為 `58c7e51`（2026-09-04），但本次期末新增之全部技術收尾（NRLMSIS 改善、ComSpOC 管線化、burn-arc 排程、本報告文件本身）皆為此 commit 之後的工作目錄變更。**建議送審前執行一次完整 commit**，使審查基準點可被唯一標定；在此之前，複核者應以「當前工作目錄」而非某個 commit 作為複核基準。
2. **歷史結果之 commit 對應**：r10 主體（八月完成之核心分析）於原分析當時未逐項記錄對應之 git commit hash，故無法逐一回溯標注每個歷史數字之精確版本；本封包之複核指令對應的是「目前程式碼＋目前資料」，結果應與報告數字一致或在合理誤差範圍內（HistGradientBoostingClassifier 多執行緒運算已知有 ±0.005 之 AUC 非決定性微抖動）。
3. **MEME 精密星曆之外部依賴**：MEME 資料來自 SpaceX 公開端點（`api.starlink.com`），非正式資料協議，其長期可用性不受本專案控制；`data/raw/` 已存有下載快照，複核者如無法重新對接該端點，建議直接索取本專案已下載之快照。
4. **大型二進位資產未納入本 Git 庫**：`space_db.duckdb`（14GB 全庫）、`data/raw/`（逐分鐘 MEME 星曆，數十 GB）因體積過大未進版本控制，複核者需另行取得（見資料治理規範文件之備份章節）。
