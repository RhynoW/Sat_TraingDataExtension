## 二、逐方法說明（新增：原文任務/資料、忠實度與可比性欄）

### 2.1 Decoto, 2015 — **審查後發現：本次實作與 Mukundan 2021 代理機制完全相同**

| 欄位 | 內容 |
|---|---|
| 原文任務/資料 | GEO 衛星站台保持機動偵測，頻域週期性訊號擬合 |
| 本次實作 | 逐相鄰TLE前向SGP4自洽殘差＋穩健z分數（**與 `lit_tier1_reproductions.
py::detect_mukundan2021` 演算法完全相同**） |
| 忠實度 | 極低——未實作原文之頻域方法，且與另一「獨立」文獻代理共用同一機制 |
| 可比性 | **不應視為與 Mukundan 2021 獨立之第二個資料點** |

**誠實揭露（2026-09-14 內部審查後自行檢查發現）**：撰寫本次實作時，因
Decoto 2015（GEO 站台保持頻域擬合）在 LEO 標竿上缺乏直接對應方法，
`detect_decoto2015` 實際重用了與 `detect_mukundan2021`（Tier1 報告 2.2 節）
完全相同的邏輯——皆為「用前一筆 TLE 之 SGP4 傳播預測當前 sma，與實際
sma 相減，穩健 z 分數門檻判定」。兩者 F1 高度相關（Decoto 版 Macro
F1=0.300、Micro F1=0.246，與 Mukundan 2021 版數字幾乎一致）並非巧合，
而是同一演算法在幾乎相同資料上跑出的結果。**因此本文與 Tier1 報告之
「15篇文獻」計數中，Decoto 2015 與 Mukundan 2021 應視為同一偵測機制之
重複計數，實質為 14 個相異之偵測機制**，已於程式 docstring 中記錄
（`lit_tierA2_reproductions.py` `detect_decoto2015` 上方注解）。原文之
GEO 頻域週期擬合方法目前**未被實作**，此為待補項目。

### 2.2 Roberts & Linares, 2021

| 欄位 | 內容 |
|---|---|
| 原文任務/資料 | GEO 經度滑動視窗特徵 + CNN 監督式分類 |
| 本次實作 | LEO 半長軸取代經度、`RandomForestClassifier`（斜率/加速度/局部標準差3特徵）取代CNN，前半段訓練、全序列預測 |
| 忠實度 | 低——任務域（GEO→LEO）、輸入量（經度→sma）、模型（CNN→RF）三處皆有替換 |
| 可比性 | 僅供本專案內部方向參考，不宜與原文 CNN 於 GEO 之性能比較 |

- Macro F1=0.376（P=0.289, R=0.707；Micro F1=0.361）——**在本實作與此
  門檻設定下，呈現高召回、低精確率的操作點**（措辭依審查意見調整，
  不歸納為監督式分類器之一般性質，因僅由單一 Precision/Recall 組合
  推導）。多顆衛星召回率逼近甚至超過 0.9（HY-2D 0.96、SPOT-3 0.92、
  HY-2C 0.92）。
- **待確認項目（審查意見）**：訓練標籤來源與訓練/預測資料是否存在
  時間洩漏（特徵之局部統計量若涵蓋評估時間點附近之未來值，會使結果
  偏樂觀），本文尚未做此項檢查，列入§六。

### 2.3 Qin et al., 2019

| 欄位 | 內容 |
|---|---|
| 原文任務/資料 | 北斗 GEO/IGSO 衛星，前向/後向軌道傳播殘差雙向交叉驗證 |
| 本次實作 | 前向SGP4殘差與後向SGP4殘差絕對值之最大值為合併訊號 |
| 忠實度 | 中——核心「雙向交叉驗證」概念保留，但軌道類型（GEO/IGSO→LEO）與傳播模型細節可能與原文不同 |
| 可比性 | 可作初步方向比較 |

- Macro F1=0.368（P=0.513, R=0.442；Micro F1=0.276）——本批 Macro
  精確率最高，顯示雙向傳播交叉驗證有助於濾除單向傳播雜訊造成的假
  警報，方向上與原文設計動機一致；但 Macro／Micro 差異較大，顯示
  部分衛星事件數對整體加總結果影響不小。

### 2.4 MDPI Aerospace 2026 — 需要更完整揭露之對照組

| 欄位 | 內容 |
|---|---|
| 原文任務/資料 | 待補完整書目資訊（見下方誠實聲明） |
| 本次實作 | Δa、Δe變化率、平均運動局部離散度三特徵，各自穩健z分數取最大值，疊代遮罩重估計 |
| 忠實度 | 中（特徵定義依論文摘要復現，未逐一核對原文完整公式） |
| 可比性 | **門檻經由本評估集內衛星（Jason-3）調校，見下方揭露** |

**誠實聲明（方法同源性，措辭依審查意見調整）**：此篇方法設計與本專案
既有方法在特徵族與統計流程上高度相近（皆屬「多特徵穩健統計＋疊代精煉」
家族）。**該結果提供了方法設計方向的相容性證據，但由於特徵族、評估
資料與部分流程高度相近，不能視為嚴格的獨立外部驗證**（審查建議措辭）。

**誠實聲明（門檻調參方式，審查後新增揭露）**：本方法之門檻由 k=5.0
（初始值，Macro P=0.088 過低）調整至 k=20.0，調整依據是**在 Jason-3
（本 23 星最終評估集之成員）上測試不同 k 值之 F1 表現**（k=5→F1=0.493，
k=30→F1=0.735），選擇 k=20 作為預設值，再用此固定值跑完整 23 星。
**Jason-3 屬於正式評估集而非獨立開發集，此調參方式構成以測試真值選擇
超參數，會使最終 F1 偏樂觀**（審查意見）。本文尚未按建議改用「獨立
validation satellite 調參、untouched test satellites 報告」或
leave-one-satellite-out 方式重做，此為§六待補之最高優先項目——在補做
之前，**本方法 F1=0.400「首次超越 headline」之結論應視為探索性
（post-hoc tuned）結果，非正式性能宣稱**。

- Macro F1=0.400（P=0.410, R=0.491；Micro F1=0.380）——本批數字最高，
  最佳單星：Sentinel-3B F1=0.781、Sentinel-3A F1=0.778、CryoSat-2 F1=0.740。
- 完整書目資訊（作者、期刊卷期、DOI）目前未能於本報告中完整列出，
  「MDPI Aerospace 2026」為概略引用，**應視為待補項目**，正式對外使用
  前須補齊。

### 2.5 Shorten et al., 2023（arXiv，最優提案粒子濾波）

| 欄位 | 內容 |
|---|---|
| 原文任務/資料 | TLE 異常偵測，最優提案粒子濾波 |
| 本次實作 | 2狀態(位置+漂移)模型，創新z分數統計量，5次迭代調整後之最終參數組 |
| 忠實度 | 中低——核心粒子濾波框架保留，但觀測/狀態模型為簡化版，且經多次超參數調整 |
| 可比性 | 僅供內部參考，調整依據未經獨立資料驗證 |

**除錯過程如實記錄**：實作過程遭遇典型粒子濾波退化（degeneracy）問題，
歷經 5 次迭代才得到目前版本：
1. 初版（單狀態位置、原始 surprise／負對數邊際概似統計量）：`obs_sigma`
   估得極小，surprise 值達 1e10 量級，門檻無法有效分離正常/異常點。
2. 二版（obs_sigma 設下限、log1p 轉換）：仍有固定高原，對門檻不敏感。
3. 三版（雙狀態位置+漂移模型，仍用 surprise 統計量）：高原惡化。
4. 四版（雙狀態模型+創新z分數）：仍達 1200+ 點——診斷為粒子退化：
   重採樣過於頻繁且擾動噪聲過小，導致 `pred_var` 塌縮至接近零。
5. **最終版**：重採樣門檻放寬、大幅提高重採樣正則化噪聲，維持創新z
   分數統計量，k=4.0。

- Macro F1=0.345（P=0.351, R=0.413；Micro F1=0.377）——最佳單星：
  Sentinel-3A F1=0.809、CryoSat-2 F1=0.731。
- **待補項目（審查意見）**：目前僅報告最終版結果，未提供消融表比較
  「重採樣門檻、正則化噪聲、狀態維度、統計量、k」各項調整之個別貢獻，
  讀者無法判斷結果改善主要來自方法設計本身或來自調參，列入§六。

## 三、共同觀察（措辭已依審查意見調整為觀察層級，非因果結論）

- 本批（Tier A2）5 個代理實作中有 4 個 Macro F1>0.3，是三批代理實作中
  平均數字最高的一批；惟其中 Decoto 2015 與 Mukundan 2021（Tier1）為
  重複機制（見§2.1），MDPI 2026 之最高分涉及測試集門檻調參（見§2.4），
  兩者皆非可直接視為「獨立驗證之優異結果」。
- Sentinel-3A／Sentinel-3B／CryoSat-2／SWOT／HY-2D 在三批代理實作與
  本專案方法中普遍表現較好，GRACE-A、GRACE-B、TOPEX/Poseidon 普遍
  較差。**在本 23 星標竿與目前評估設定下，衛星間性能差異大於多數方法
  間的平均差異；但此結果可能同時受衛星世代、軌道類型、資料品質與
  事件分布影響，尚不能分離各因素的個別因果貢獻**（措辭依審查意見
  調整）。
- 「雙向（前向＋後向）傳播交叉驗證」（Qin 2019）之設計概念，值得作為
  本專案後續消融實驗之候選方向；惟目前僅有單一資料點，尚未做敏感度
  分析或跨衛星穩健性驗證。
