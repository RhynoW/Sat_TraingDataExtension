# GEESAT 2-05  (NORAD 58909)

## 基本資訊
| 欄位 | 值 |
|------|-----|
| COSPAR ID | 2024-023E |
| 星座 / 系列 | GEESATCOM（吉利星座），第二批次 |
| 運營商 | Geespace（時空道宇），吉利控股集團旗下 |
| 任務類型 | IoT 物聯網通訊 / AIS 船舶識別 |
| 發射日期 | 2024-02-02 |
| 發射場 | 西昌衛星發射中心（XSC） |
| 運載火箭 | 長征二號丙（CZ-2C）（推測） |
| 軌道 | LEO，~600 km，傾角 50° |
| 質量 | ~130 kg |

## 任務背景
GEESAT 2-05 是 GEESATCOM 第二批次 11 顆衛星中的第五顆，2024 年 2 月 2 日從西昌發射。GEESATCOM 採用 50° 傾角低軌設計，選擇西昌（28.2°N）發射可直接注入較低傾角軌道，減少入軌後所需的傾角調整推進劑消耗。

GEESAT 衛星搭載物聯網通訊載荷（L/S 頻段窄帶）及 AIS 接收器，具備星上數據處理能力，可在地面站不可見時暫存感測數據，後續過境時批量下傳。

## 機動行為分析
入軌後執行相位機動達到第二軌道面設計槽位。2024 年 2-3 月為機動活躍期。2025 年機動活動可能因常規軌道維持（補償 600 km 高度的大氣阻力）引起，估計每月推力修正 1-2 次。
