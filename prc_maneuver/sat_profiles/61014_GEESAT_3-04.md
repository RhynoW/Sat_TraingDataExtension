# GEESAT 3-04  (NORAD 61014)

## 基本資訊
| 欄位 | 值 |
|------|-----|
| COSPAR ID | 2024-159D |
| 星座 / 系列 | GEESATCOM（吉利星座），第三批次 |
| 運營商 | Geespace（時空道宇），吉利控股集團旗下 |
| 任務類型 | IoT 物聯網通訊 / AIS 船舶識別 |
| 發射日期 | 2024-09-05 |
| 發射場 | 太原衛星發射中心（TSC） |
| 運載火箭 | 長征六號（CZ-6）（推測） |
| 軌道 | LEO，~600 km，傾角 50° |
| 質量 | ~130 kg |

## 任務背景
GEESAT 3-04 是 GEESATCOM 第三批次（2024 年 9 月，從太原發射）衛星，在軌序號為第四顆。第三批次完成後，吉利星座在軌衛星超過 30 顆，初步達到部分軌道面的多重覆蓋。

GEESATCOM 的 COSPAR 2024-159 批次從太原發射，與第二批次（西昌）不同，反映了 GEESATCOM 靈活利用多個發射場的策略。太原適合發射中傾角及 SSO 軌道，配合長征六號的多星共乘能力，可高效批量部署小衛星。

## 機動行為分析
入軌後執行相位展開機動達到第三軌道面設計槽位。2024 年 9-10 月機動集中。2025 年若存在機動，可能為週期性軌道維持推力或碎片規避機動。
