# GEESAT 4-02  (NORAD 65120)

## 基本資訊
| 欄位 | 值 |
|------|-----|
| COSPAR ID | 2025-170B |
| 星座 / 系列 | GEESATCOM（吉利星座），第四軌道面 |
| 運營商 | Geespace（時空道宇），吉利控股集團旗下 |
| 任務類型 | IoT 物聯網通訊 / AIS 船舶識別 |
| 發射日期 | 2025-08-08 |
| 發射場 | 海上發射平台，黃海（YSLA） |
| 運載火箭 | 捷龍三號（Smart Dragon-3 / Jielong-3） |
| 軌道 | LEO，~600 km，傾角 50° |
| 質量 | ~130 kg |

## 任務背景
GEESAT 4-02 屬 GEESATCOM 第四軌道面批次，於 2025 年 8 月 8 日由捷龍三號從黃海海上平台發射。這是 GEESATCOM 在兩個月內完成的三次連續部署之一。

2025 年 8 月的第四軌道面發射共攜帶 11 顆衛星，使在軌衛星數量達 41 顆，首次達到可提供全球一層 IoT 覆蓋的門檻。吉利公告稱此批次配備 AI 遙感功能，解析度達 3.2 ft～16.4 ft，可兼顧通訊服務與商業遙感業務。

## 機動行為分析
入軌後執行相位展開機動至第四軌道面設計槽位，並進行高度調整。2025 年 8 月下旬至 9 月初機動集中，屬入軌部署期正常機動行為，之後轉入常規站保。
