# GEESAT 4-05  (NORAD 65123)

## 基本資訊
| 欄位 | 值 |
|------|-----|
| COSPAR ID | 2025-170E |
| 星座 / 系列 | GEESATCOM（吉利星座），第四軌道面 |
| 運營商 | Geespace（時空道宇），吉利控股集團旗下 |
| 任務類型 | IoT 物聯網通訊 / AIS 船舶識別 |
| 發射日期 | 2025-08-08 |
| 發射場 | 海上發射平台，黃海（YSLA） |
| 運載火箭 | 捷龍三號（Smart Dragon-3 / Jielong-3） |
| 軌道 | LEO，~600 km，傾角 50° |
| 質量 | ~130 kg |

## 任務背景
GEESAT 4-05 屬 GEESATCOM 第四軌道面批次，與同批 10 顆姊妹星共同於 2025 年 8 月 8 日入軌。截至此次發射，GEESATCOM 在軌衛星數量達 41 顆，正式具備全球一重覆蓋能力，商業服務可用性達到電信級標準（99.97%）。

Geespace 在 2025 年連續執行三次海上發射，分別部署第四、第五、第六軌道面，展示了中國商業低軌星座快速建設的能力，也驗證了捷龍三號固體火箭的高頻次使用可靠性。

## 機動行為分析
與同批次衛星相同，入軌後執行相位展開機動達到設計槽位，之後進入常規軌道維持。2025 年 8 月為機動活躍期。
