# GEESAT 4-09  (NORAD 65127)

## 基本資訊
| 欄位 | 值 |
|------|-----|
| COSPAR ID | 2025-170J |
| 星座 / 系列 | GEESATCOM（吉利星座），第四軌道面 |
| 運營商 | Geespace（時空道宇），吉利控股集團旗下 |
| 任務類型 | IoT 物聯網通訊 / AIS 船舶識別 |
| 發射日期 | 2025-08-08 |
| 發射場 | 海上發射平台，黃海（YSLA） |
| 運載火箭 | 捷龍三號（Smart Dragon-3 / Jielong-3） |
| 軌道 | LEO，~600 km，傾角 50° |
| 質量 | ~130 kg |

## 任務背景
GEESAT 4-09 屬 GEESATCOM 第四軌道面批次（共 11 顆），2025 年 8 月 8 日發射。此批次完成後，吉利星座在商業服務中實現全球物聯網連結覆蓋，商業測試成功率達 99.15%。

衛星採用捷龍三號固體運載火箭的海上發射模式，避免了陸地發射場的排期衝突，可以更靈活地選擇發射窗口，滿足星座快速建設需求。捷龍三號單次可搭載約 1,560 kg 至 500 km SSO，具備多星共乘能力，適合批量部署小衛星。

## 機動行為分析
入軌後執行相位機動達到第四軌道面目標槽位，期間 TLE 呈現系統性半長軸與偏心率變化，被識別為機動事件。後期轉入常規站保。
